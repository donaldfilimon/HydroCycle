# HydroCycle unified Next.js visual references

These six images are the accepted implementation references for the unified
HydroCycle web application:

- `summary-desktop.png` and `summary-mobile.png`
- `workbench-desktop.png` and `workbench-mobile.png`
- `test-runs-desktop.png` and `test-runs-mobile.png`

The earlier `docs/design/summary.png`, `workbench.png`, and `test-runs.png`
remain authoritative for product hierarchy and scientific meaning. Numeric
values and small labels in every concept image are illustrative; production UI
values must come from generated contracts, the local model service, or the
canonical deterministic fixtures.

The canonical brand mark is an evolved, code-native SVG form of the original
HydroCycle wave. It must remain consistent across the application shell,
favicon, metadata, and Open Graph asset.

## Visual system

- Summary and evidence-ledger surfaces use true pearl white with a cool,
  technical grid.
- Workbench and comparison surfaces use obsidian and indigo.
- Electric cobalt is the primary action color. Hydrogen cyan, ultraviolet,
  amber thermal, green pass, and red failure are reserved semantic accents.
- Display text is geometric and compact; measurements and evidence identifiers
  use monospaced numerals.
- Corners are chamfered or minimally rounded. Borders are thin and precise.
  Glow is restrained to dark data surfaces.
- Chamber and cycle imagery is code-native and schematic. Never depict flame
  fronts, CFD fields, velocity vectors, particle trajectories, or photoreal
  engine behavior.

## Fidelity acceptance

Implementation screenshots must be captured at 1536 x 1024 and at a Pixel 7
viewport. Review copy, layout, type hierarchy, palette, component geometry,
chart treatment, and responsive behavior against the matching reference. Any
intentional deviation must be recorded in the final fidelity ledger.
